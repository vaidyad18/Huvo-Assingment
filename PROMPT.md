# Northstar One System Prompt

The complete production prompt is stored in `app/prompt.py`.

The prompt is responsible for:
- Project factuality
- Natural conversational behaviour
- English, Hindi and Hinglish
- Lead qualification
- Budget handling
- Objection handling
- Follow-up
- Human escalation
- Site-visit flow
- Booking-result handling
- Conversation closure
- Preventing unsupported claims

The application sends this prompt as Gemini's system instruction on every
AI response.
