# Northstar One AI Conversational Sales Bot

A simple FastAPI + Gemini conversational sales assistant built for the
Forward Deployed Engineer assignment.

## Architecture

Browser
→ FastAPI
→ Gemini API
→ System Prompt + Conversation History
→ AI Response

The application does not use predefined conversational responses as the
normal response path. Every assistant reply is generated by Gemini.

Lead information is tracked separately so analytics can be shown after the
conversation.

## Tech Stack

- Python
- FastAPI
- Google Gemini API
- `google-genai` SDK
- HTML/CSS/JavaScript
- In-memory session state

Google's Gemini API supports system instructions and multi-turn conversation
content, which are used by this implementation.

## Setup

Create a virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Create `.env` from `.env.example` and add your Gemini API key.

Example:

```env
GEMINI_API_KEY=your_api_key_here
GEMINI_MODEL=gemini-3.8-flash
```

Start the application:

```bash
uvicorn app.main:app
```

Open:

```text
http://127.0.0.1:8000
```

## AI Behaviour

Gemini receives:
1. The Northstar One system prompt.
2. Recent conversation history.
3. Application-generated booking context when a site-visit booking is attempted.

This allows Gemini to generate the actual customer-facing response while the
application maintains deterministic state and booking simulation.

## Booking Simulation

The assignment asks for simulated site-visit booking.

The simulator succeeds for normal date/time inputs.

For deterministic failure testing:
- A time of `00:00` fails.
- A date/time containing `fail` fails.

The booking result is then passed to Gemini so the customer-facing response
is still AI-generated.

## Tests

Run:

```bash
pytest
```

AI integration tests require `GEMINI_API_KEY`.

## Assumptions

- Session state is stored in memory.
- Booking is simulated.
- No real CRM or calendar is connected.
- No real inventory or availability is claimed.
- The project facts are intentionally limited to the facts provided in the
  assignment.

## Limitations

- Restarting the server clears sessions.
- The booking system is only a deterministic simulator.
- Lead extraction is lightweight and stored separately from the AI response.
- Voice input is not implemented in this text-based demo.

## AI Tool Used

Google Gemini API through the official `google-genai` Python SDK.

No API key is committed to the repository.
